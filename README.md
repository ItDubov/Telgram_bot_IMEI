# IMEI Check Backend System

Этот проект представляет собой бэкенд-систему для проверки IMEI устройств, интегрированную с Telegram-ботом и предоставляющую API для внешних запросов. Система интегрируется с сервисом [IMEI Check](https://imeicheck.net/), который предоставляет информацию о статусе IMEI.

## Описание

Система включает в себя несколько компонентов:
1. **Telegram-бот** — для проверки IMEI через чат с пользователем.
2. **API** — для проверки IMEI через HTTP-запросы.
3. **Авторизация** — через белый список пользователей для Telegram-бота и токен для API.

### Основной функционал:
1. Проверка IMEI через API и Telegram-бот.
2. Белый список пользователей для бота.
3. Авторизация по токену для API.

## Установка

### Требования
Для запуска системы требуется:
- Python 3.8 или выше
- Установленные библиотеки:
  - `Flask` — для API.
  - `python-telegram-bot` — для работы с Telegram-ботом.
  - `requests` — для отправки HTTP-запросов к сервису IMEI Check.

### Установка зависимостей

Для установки зависимостей создайте виртуальное окружение и установите необходимые библиотеки:

Функционал
1. Telegram-бот
Белый список пользователей
Для доступа к функционалу бота, необходимо добавить пользователя в белый список. Бот будет проверять ID пользователя перед тем, как выполнять запросы.

Проверка IMEI
Пользователь может отправить IMEI своему боту, и он получит ответ с информацией о валидности IMEI.

Бот проверяет IMEI на валидность с помощью интеграции с сервисом IMEI Check.
Ответ будет включать информацию о статусе IMEI.
Пример взаимодействия:
Пользователь отправляет боту IMEI.
Бот проверяет IMEI на валидность.
Бот отправляет результат проверки в чат.
2. API
Авторизация
Для доступа к API необходимо передавать токен авторизации в каждом запросе. Токен должен быть передан в параметре token.

Запрос на проверку IMEI
Метод: POST /api/check-imei

Параметры запроса:

imei (строка, обязательный) — IMEI устройства.
token (строка, обязательный) — токен авторизации.
Пример запроса:

curl -X POST http://localhost:5000/api/check-imei \
  -d "imei=123456789012345" \
  -d "token=<your-api-token>"
Ответ (JSON):


json

{
  "imei": "123456789012345",
  "valid": true,
  "manufacturer": "Apple",
  "model": "iPhone 12",
  "status": "active"
}
